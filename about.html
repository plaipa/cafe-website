قهوه، ایده، جمع.

Code Concept جایی است برای کسانی که با یک فنجانِ خوب فکر می‌کنند، می‌سازند و دورِ هم جمع می‌شوند.

code
concept

کد
دقت. وزن، دما و زمان؛ قهوه هم مثلِ کد، وقتی جزئیاتش درست باشد کار می‌کند.
کانسپت
ایده. میزهایی برای کار، طراحی و فکرهای تازه.
کامیونیتی
جمع. دورهمی‌ها، گفت‌وگوها و آدم‌هایی که همدیگر را پیدا می‌کنند.

سه چیز که ما را می‌سازد

  1. ۰۱ — قهوه

    از دانه تا فنجان

    دانه‌ها را با دقت انتخاب می‌کنیم و هر فنجان با دستورِ ثابت و تکرارپذیر دم می‌شود.

  2. ۰۲ — فضا

    بتن، استیل و نور

    فضایی آرام و مینیمال؛ برای یک ساعت تمرکز یا یک گفت‌وگوی طولانی.

  3. ۰۳ — جمع

    کامیونیتیِ Code Concept

    دورهمی‌ها و رویدادهایی برای آدم‌های کنجکاو، سازنده و خلاق در تبریز.

قهوه بهانه است؛ ایده‌ها و آدم‌ها اصل‌اند.
